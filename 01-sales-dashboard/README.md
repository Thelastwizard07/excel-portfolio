# Project 01 — Sales Dashboard

## Overview

This project analyzes 100 sales transactions using Microsoft Excel.

The dataset covers sales transactions from January to September 2026 and is used to identify sales performance by product, city, and period.

## Tools

* Microsoft Excel
* Excel Formulas
* Lookup Functions
* SUMIFS
* Data Analysis
* Dashboard

## Key Analysis

The analysis includes:

* Total Sales
* Total Transactions
* Total Quantity Sold
* Average Sales per Transaction
* Sales by Product
* Sales by City
* Product Ranking
* Sales Performance Dashboard

## Dataset

The dataset contains the following information:

* Date
* Salesperson
* Product
* Category
* City
* Quantity
* Price
* Discount
* Total Sales

## Objective

The objective of this project is to analyze sales performance and present the results in an interactive and easy-to-understand Excel dashboard.

## Workbook Structure

The workbook consists of three main sheets:

1. **Raw Data** — contains the original sales transaction data.
2. **Calculation** — contains calculations and sales analysis.
3. **Dashboard** — presents key performance indicators and visualizations.

## Key Insights

The dashboard provides an overview of sales performance and helps identify differences in sales across products and cities.

## Output

The final output is an Excel-based sales analysis and dashboard designed as part of my data analysis portfolio.
